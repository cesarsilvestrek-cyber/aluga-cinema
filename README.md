# Aluga Cinema — projeto escolar

Site estático demonstrativo de aluguel e compra de filmes.

## Publicação
O site é publicado pelo GitHub Actions usando GitHub Pages sempre que há um push para `main`.

No repositório, acesse **Settings → Pages** e confirme **Source: GitHub Actions** caso seja solicitado.

## Recursos
- Catálogo com busca, categorias e ordenação.
- Aluguel demonstrativo de 2h, 5h, 24h e 48h, além de compra digital.
- Carrinho e checkout em etapas.
- Login ilustrativo com CPF. Não informe CPF real; não há servidor.
- Pix, cartões, boleto e carteira digital são apenas simulações; não há cobrança.
- Selos de Reclame AQUI e Google Safe Browsing são demonstrativos, não certificados/parcerias reais.

## Direitos
Filmes, pôsteres, marcas e nomes pertencem aos respectivos titulares. Os elementos são usados como protótipo escolar. Verifique as licenças antes de qualquer uso público ou comercial.
